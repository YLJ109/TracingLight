# 溯光 TracingLight · 全面升级方案（v3）

> 日期：2026-09-04　|　依据：用户模块化升级需求 + 逐项代码侦察定位
> 原则：教师端考试管理**保留**；先方案后实施；每项给出根因与落地方式。

---

## 一、UI 与布局修复（根因已定位）

### 1.1 AI 出题「生成中的盒子」过长
- **根因**：`ai-generate` 右侧结果区 `min-h-[400px] h-full` 与外层 grid 叠加，生成态/多结果时整页被撑出视口；新建作业页 AI 面板同理。
- **方案**：结果区改为固定视口内滚动（`max-h` + `overflow-y-auto`），生成态高度自适应（去 400px 下限），页面总高锁定视口。

### 1.2 知识图谱/思政 Tab 跑到右侧 + 作用不明确
- **根因**：能力/思政视图的 header 使用 `justify-between`，Tab 被推到最右；卡片仅有名称+关联知识点，无掌握度联动与行动入口。
- **方案**：Tab 移回标题右侧同行（与知识视图一致）；能力/思政卡片补充「去学习（关联知识点材料）」「问 AI 老师」入口，并展示关联知识点掌握度。

### 1.3 树图未居中
- **根因**：D3 初始定位 `zoomIdentity.translate(W/2, H/2)` 仅适配**径向**布局；横向树布局下根节点被画到画布中心，导致整体偏右下、无法四向居中。
- **方案**：按 viewMode 分别设置初始 translate（radial 保持中心；horizontal 用左留白 + 垂直按树高居中），缩放重置同步修正。

## 二、功能完善与重构

### 2.1 AI 出题不显示选项/答案/解析（**已定位为崩溃级 bug**）
- **根因**：预览卡把 `options` 对象直接作为 React 子节点渲染（`{q.options}`）——"Objects are not valid as a React child"，选项存在时**整卡崩溃**，表现为"不显示选项/答案/解析"。
- **方案**：选项逐项格式化渲染（A/B/C/D 列表）；详情默认展开；每题加**勾选框**，「确认入库」仅入库勾选题目（手动选题）。

### 2.2 新建作业选题分页
- **方案**：题库列表每 10 题一页（页码 + 上一页/下一页），已选题数量常驻显示，"下一步"前置校验提示；筛选（题型/难度/知识点）与分页叠加。

### 2.3 作业退回重做闭环（参考学习通）
- **现状**：学生可随时 `?redo=true` 重做，无教师退回概念，流程不闭环。
- **方案**：
  1. `answer` 表新增 `returned / returned_at / return_comment` 字段（DDL + 现库 ALTER 迁移）；
  2. 教师批改页每个学生新增「退回重做」（可附退回理由）→ 写 answer.returned=true，清 is_submitted 门控；
  3. 学生作业列表显示「已退回」徽标；详情页仅当 `returned=true` 出现「重做作业」按钮（彻底移除自由 redo 入口）；
  4. 学生重做提交后 `returned` 复位、重新进入批改流程 → 教师可再次批改/退回，形成闭环；
  5. 退回时发通知（复用批改通知机制）。

### 2.4 学习材料重设计
- **现状**：有材料列表 + 停留时长上报，但学完无出口、与知识点/错题无联动，"用途不清"。
- **方案**：材料卡升级——显示关联知识点、我的学习状态（未学/学习中/已完成 + 进度条）；学完弹出「下一步」三入口（去错题本 / 问 AI 老师 / 看关联图谱）；页首说明改写为价值导向文案；与行为记录联动展示"已投入时长"。

## 三、数据与推荐升级

### 3.1 学情分析
- 数据源已全真实（前轮治理）；本轮补：看板学生卡片补齐学生信息展示（班级/层级/正确率），剔除重复统计块。

### 3.2 个性化推荐
- 每条推荐增加**推荐理由**（基于真实数据：如"近 3 次该知识点错误 2 次"）与**一键行动**（去练习/看材料/问 AI），避免"只给清单不给路径"。

## 四、管理端加固

- **AI API 配置与切换**：管理端"系统设置"新增 AI 服务配置卡（Base URL / API Key / 模型名），存入 `system_config` 表；`ai/client.ts` 启动与调用时读取 DB 配置（DB 优先、env 兜底），**切换即时生效**（无需重启）。
- 其余管理信息（用户/课程/日志）已具备真实读写，保持。

## 实施顺序
1. UI 三修复（1.1/1.2/1.3）→ 2. 出题崩溃修复+勾选入库+分页 → 3. 退回重做闭环 → 4. 材料重设计 → 5. 推荐/学情增强 → 6. 管理端 API 配置 → 7. 全量验证（tsc/单测/浏览器实测）
