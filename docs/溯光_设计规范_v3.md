# 溯光 TracingLight · 前端设计规范 v3

> 模式：Redesign · Preserve（功能与数据逻辑零改动，仅视觉/布局/交互层升级）
> 视觉语言：**安静的学术工具感 + 粉紫品牌点缀**（参考 Linear/Notion 的工具质感）
> 旋钮：VARIANCE 4 · MOTION 3 · DENSITY 6 · 品牌保真 9

---

## 1. 色彩

| 用途 | 值 | 规则 |
|---|---|---|
| 页面底色 | `.page-surface`（冷白 oklch 0.978 + 右上品牌光晕） | 禁止再用 `bg-[#fafbfc]`/`bg-slate-50` 硬编码 |
| 品牌主色 | `bg-violet-600 hover:bg-violet-700`（实色） | 渐变只允许出现在登录品牌面板 |
| 品牌渐变时刻 | 仅登录页左侧品牌面板 + 三端侧栏品牌区 | 页面内渐变按钮一律实色化 |
| 语义色 | 成功 emerald-600 / 错误 red-500/600 / 警告 amber-600 | 对错着色：学生答案对绿错红，参考答案绿 |
| 中性文字 | foreground token / muted-foreground | 新代码禁止 slate 硬编码（存量逐步迁移） |

## 2. 排版

| 层级 | 类 | 说明 |
|---|---|---|
| 页标题 | `.page-title` | clamp(1.15–1.5rem) / 700 / tracking -0.02em，自动平衡换行 |
| 页副题 | `.page-subtitle` | 13px muted |
| 区块标题 | `.section-title` | 15px / 600 |
| 正文/辅助 | text-sm / text-xs | 沿用 |

页标题与正文比例 ≈ 2.3×，修复全站 text-sm 无对比的问题。

## 3. 表面与间距

- 卡片统一 `.surface-card`（+`.surface-card-hover` 可悬浮）；新代码不再手写 `border-0 shadow-sm bg-white` 组合
- 页面容器：`p-4 lg:p-6 space-y-6`；卡片内 `p-4`（紧凑 `p-3`）
- 圆角：卡片 rounded-2xl / 控件与输入 rounded-xl / 小按钮 rounded-lg
- 阴影三级：card（微）→ hover（升）→ modal（重）

## 4. 动效

- 统一 150–200ms ease-out；按压 `scale(0.98)` 全局生效
- 列表入场 `.animate-stagger`；页面 `.animate-fade-in-up`
- `prefers-reduced-motion` 全局降级

## 5. 交互一致性

- 全局 `:focus-visible` 品牌描边（键盘可达）
- 按钮五态齐备（hover/active/focus/disabled/loading）
- 空态用 `.empty-state` + 图标 + 引导文案；加载统一 skeleton-shimmer
- 错误信息一律中文 + 行动指引（AI 未配置 → 503 引导管理端）

## 6. 响应式断点

- lg(1024) 三端侧栏切换为移动 TabBar/横滚条
- 表格与宽内容 `overflow-x-auto`；消息气泡 max-w 85%
- 触控目标 ≥ 40px（tab/按钮 h-9+）
