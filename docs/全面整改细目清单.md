## 三、英文标签整改清单

**扫描规则（实施阶段按此全端核对，学生/教师/管理三端 page.tsx + route.ts）：**
1. JSX 文本节点里的英文单词/短语 → 应改中文；
2. 状态/类型映射字典的“缺失回退”分支 `LABEL[x] ├─x`、`x.label├─x` → 补齐字典并用默认中文 `├─'未知'`，杜绝英文回退；
3. 把 `status/type/role/state/review_status/student_level` 等英文原值直接当 UI 文案 → 强制映射；
4. 半中半英、拼音文案 → 统一中文。

**已确认实例（采样，非穷尽）：**

| 端 | 文件:行号 | 实例 | 建议 |
|----|-----------|------|------|
| 学生 | `knowledge-graph/page.tsx` 图例/筛选区域 | 图表年份/前缀若有英文需核 | 中文 |
| 教师 | `teacher/exams/page.tsx#L203-218` | `STATUS_META[e.status] ├─ STATUS_META.draft`、`TYPE_LABEL[e.exam_type] ├─'考试'`，未知枚举回退英文 | 补全字典+默认中文 |
| 教师 | `teacher/exams/[id]/report/page.tsx#L42-47` | `STATE_LABEL/SUBMIT_VIA_LABEL` | 全值覆盖，并 `├─'未知'` |
| 教师 | `teacher/analytics/page.tsx#L78,604` | `errorTypeLabel(e.type)` 缺值回退 | 补全错因枚举中文 |
| 管理 | `admin/users/page.tsx#L120-139` | 角色/状态已中文；`student_level` 确保 `top/medium/weak`→`学霸层/勤奋中等层/提升层` | 补充映射 |

> 完整三端英文标签全量清单 → 实施期用上述规则端内逐文件核对生成，此处给出规则防遗漏。

## 四、种子数据重构细目（与口径一致・可演示联动）

结构基调（已实现，需回归 + 增强）：

| 项 | 目标 | 现状/增强点 |
|----|------|-------------|
| 组织 | 2班×10生、2教师(各1班2门课)、1管理员+1助教、4课程 | 已符合 |
| 作业 | 每课 **6** 份：2已批改公布 / 2已作答待批改 / 2待作答 | **修复F1后6份全可见** |
| 考试 | 每课 4 场：2 完成公布 / 2 待考 | 核对 closed 是否被学生端隐藏（同 F1 口径） |
| 题库 | 6 题型各 ≥40；`knowledge_point_id` 非空 | 已 240 题 |
| 图谱 | 每课 20 知识点（4章×5）+ 前置边 | 已 100 节点/76 边 |
| **联动自洽** | **知识点 ↔ 错题(error_book) ↔ 掌握度(log) 在 `knowledge_point_id` 上真实关联且数据自洽** | 需增强：错题归属于对应知识点、分层 top/medium/weak 与掌握度/错题数正相关（避免“勤奋中等层却 82/100 未学”突兀） |

> 冲突修复后产品口径：
> - 已批改(closed+published)作业学生**可见**并可看成绩；
> - 考试已公布(closed+grades_published)学生**可见**结果；未公布不可见。
