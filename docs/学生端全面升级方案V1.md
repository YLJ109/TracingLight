# 学生端全面升级方案 V1

> 范围：学生端全部入口页面 · 数据驱动 · 体验一致性 · 可回归
> 目标：让"后端已算好的数据"全部在界面上体现，消灭"算而出不明、存而看不到、明而无引导"三类问题

---

## 一、总体诊断（先回答"为什么总觉得数据少"）

**核心结论：不是没有数据，是界面没把它展示出来。**

以"个性化推荐-总览"为典型，API（`src/app/api/student/recommend/route.ts`）已返回：
`overallMastery`、`strongCount / mediumCount / weakCount`、`totalErrors`、`radarData(8维)`、`trendData(逐作业趋势)`、`courseComparison(课程对比)`、`knowledgeMastery`、`courses`。

但前端 `src/app/student/recommend/page.tsx` 的"总览"tab **只渲染了 AI 洞察 + 近期考试两小块**，上面这堆核心指标一句话都没用，页面因此显得"空"。这是全项目最典型的问题——**数据早就算好了，界面没消费**。

各功能共性问题：

| 问题类别 | 表现 | 涉及功能 |
|---------|------|---------|
| 展示密度低 | 总览页只放 2 个小卡片，大量指标没上屏 | 总览、首页 |
| 数据未联通 | 知识点/错题/材料互相不跳转，点击无响应 | 全部 |
| 缺空态/骨架 | 无数据时白屏或空转，无引导 | 全部 |
| 缺统计口径 | 同学情/作业/考试口径不一致，数字对不上 | 学情、作业、考试 |
| 缺进度感知 | 不知道"今天该学什么、还剩多少" | 今日、学习规划 |
| 视觉密度不均 | 卡片无垂直呼吸感、图标孤立、换行错乱 | 全部（详见用户偏好） |

---

## 二、升级原则（贯穿全项目）

1. **单一事实源**：掌握度分级阈值（`src/lib/domain.ts`）、课程作用域（`user.class_id`）、统计口径全项目统一，禁止各页面自算一套。
2. **后端算好、前端只负责呈现**：聚合计算放 API，前端不再重复造轮子，避免口径漂移。
3. **数据->洞察->行动**：每张卡都要回答"看到什么 -> 说明什么 -> 该做什么（可跳转按钮）"。
4. **空态即引导**：无数据时给出下一步操作，而不是空白 loading。
5. **加载即骨架**：统一 `DashboardSkeleton`，避免白闪。
6. **视觉一致性**：统一圆角/阴影/渐变/间距规范，卡片有垂直呼吸感，图标必配文字。

## 三、逐功能升级方案

### 1. 个性化推荐 · 总览（本次重点，P0）

现状：总览只放"AI 洞察 + 近期考试"两小块，数据稀疏。
升级（复用 API 已返回字段，参考学情总览 `overview/page.tsx` 的图表实现）：

- **顶部指标条（4 大 KPI 卡）**：综合掌握度 `overallMastery`、已掌握 `strongCount`、需加强 `mediumCount`、累计错题 `totalErrors`。渐变底+大数字+趋势箭头。
- **能力雷达图（ECharts）**：直接用 `radarData` 的 8 维，替换现在枯燥的纯文字。
- **成绩/掌握度趋势折线图**：用 `trendData`（逐作业），标注升降。
- **课程对比横向条形图**：用 `courseComparison`，一眼看出哪科拖后腿。
- **优先级行动区**：把 `weakPoints` 前 3 个 P0 的"一键行动"（专项错题复习/问 AI/今日学习）提前到总览。
- 保留并美化 AI 洞察、近期考试，但从"唯二内容"降级为"局部卡片"。

预期效果：总览从"2 张卡"变为"4 KPI + 3 图 + 行动区"的完整驾驶舱，且全部是真实数据。

### 2. 学生首页 `/student`（P0）

- 补齐"今日待办、进度条、快捷入口"驾驶舱；无任务时给引导而非空白。
- 关键指标（待办数、错题待复习、近期考试、掌握度）上屏并可跳转。

### 3. 今日学习 `/today`（P0）

- 明确"今天该学什么"：按薄弱优先级 + 未完成材料 + 待复习错题生成今日清单。
- 逐项完成态勾选 + 总体进度条（如 28%）。保证数据真实落地而非占位。

### 4. 知识图谱 `/knowledge-graph`（P1）

- 强化已修的"错题本联动 + 课程作用域"，补全空态与图例。
- 节点点击信息面板与薄弱点/材料/学习规划跳转打通。

### 5. 错题本 `/errors`（P1）

- 增加错题类型分布、错误率统计、复习周期（`next_review_at`）可视化。
- 增加"已掌握"与"待复习"状态切换与进度。

### 6. 学习规划（StudyPlanPanel）（P1）

- 有构件时展示进度/完成率；无规划时空态引导创建。
- 与今日学习、薄弱点打通。

### 7. 学情总览 `/overview`（P1）

- 复查口径一致性（作业/考试/能力分项与其它页对齐）。
- 完善各 tab 空态与骨架；考试表现 tab 数据填充。

### 8. 学习材料 `/materials`、学习 `/learn`（P2）

- 补齐观看进度、待学列表、完成态；材料与知识点跳转相连。

### 9. 作业 / 考试 / 通知 / 公告 / 讨论区 / AI 答疑（P2)

- 统一空态、骨架、加载体验；跨页跳转打通；口径与学情页对齐。
- 列表分页或加载更多，避免长列表一次性渲染。

## 四、统一视觉规范（用户偏好落地）

- 卡片统一：`rounded-2xl + border + shadow-sm`，内边距 `p-5/6`，**保证垂直呼吸感**。
- 图表统一：`initChart` + ECharts，白底圆角 tooltip、四色语义（绿=已掌握/琥珀=需加强/红=薄弱/主色 teal）。
- 图标规范：**图标必配文字**，禁止孤立图标；单行放得下不要换行成两行。
- 按钮：渐变底 + 阴影 + hover 过渡（如 `.gradient-btn`）。
- 空态：图标 + 一句说明 + 一个行动按钮，替代"空白卡"。

## 六、风险与回归

- **口径一致**：所有聚合只允许在后端做，前端不得新造公式，防止数字对不上。
- **图表内存**：ECharts 实例必须在 useEffect cleanup 中 `dispose()`，防"已存在实例"报错。
- **空数据**：所有 API 字段为空时前端必须有备选渲染（空态），杜绝 undefined 崩溃。
- **回归清单**：升级后对登录、各 tab 切页、跳转链路、掌握度/错题数字逐一核对。
